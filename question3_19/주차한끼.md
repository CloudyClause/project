# 주차한끼

착한가격업소, 식품안심업소, 전국 공영주차장 공공데이터를 결합하여  
**차로 방문하기 좋은 가성비 음식점을 찾을 수 있도록 도와주는 모바일 생활정보 앱**입니다.

사용자는 현재 위치 또는 원하는 지역을 기준으로 음식점을 검색하고, 음식점의 가격 정보와 식품안심 여부, 주변 공영주차장의 거리·운영시간·요금 등을 함께 확인할 수 있습니다.

---

# 1. 프로젝트 개요

## 서비스명

**주차한끼**

## 핵심 메시지

> 가격도 확인하고, 안심하고 먹고, 주차까지 편하게.

## 서비스 목적

일반 지도 서비스에서는 음식점과 주차장을 각각 찾아야 하는 경우가 많습니다.

주차한끼는 다음 3가지 공공데이터를 하나의 사용자 흐름으로 연결합니다.

```text
착한가격 음식점 탐색
        ↓
식품안심 여부 확인
        ↓
주변 공영주차장 비교
        ↓
주차장 선택
        ↓
카카오맵 길찾기
```

# 5. 사용 공공데이터

이 프로젝트는 총 3개의 공공데이터를 사용합니다.

## 5.1 착한가격업소

### 역할

앱의 기본 음식점 데이터를 제공합니다.

### 주요 사용 정보

- 업소명
- 업종
- 대표메뉴
- 가격
- 주소
- 지역정보
- 전화번호 등

### 활용

- 음식점 목록
- 검색
- 음식 종류 필터
- 가격 필터
- 상세정보

---

## 5.2 식품안심업소

### 역할

착한가격 음식점이 식품안심업소인지 추가로 확인하는 용도로 사용합니다.

### 활용 방식

착한가격업소 전체를 대상으로 하며, 식품안심업소 데이터와 매칭되는 경우에만 다음 배지를 표시합니다.

```text
식품안심
```

식품안심업소가 아닌 착한가격업소도 검색 결과에서 제외하지 않습니다.

즉:

```text
착한가격업소 = 기본 데이터

식품안심업소 = 추가 신뢰정보
```

구조입니다.

---

## 5.3 전국주차장정보

### 역할

선택한 음식점 주변의 공영주차장을 찾는 데 사용합니다.

### 주요 사용 정보

- 주차장명
- 주소
- 위도
- 경도
- 주차구획수
- 운영요일
- 운영시간
- 무료/유료 여부
- 기본주차시간
- 기본요금
- 추가단위시간
- 추가요금
- 결제방법
- 관리기관
- 전화번호

### 주의

`주차구획수`는 전체 주차면 수입니다.

실시간 남은 주차 자리 수가 아닙니다.

따라서 앱에서는 다음과 같은 표현을 사용하지 않습니다.

```text
남은 자리 32개
```

대신:

```text
총 주차구획 82면
```

처럼 표현합니다.

# 7. 착한가격업소 API 설정

착한가격업소 API는 제공기관 또는 지역에 따라 요청 URL과 응답 필드 구조가 다를 수 있습니다.

따라서 `js/script.js` 상단의 다음 부분을 확인합니다.

```javascript
const API_CONFIG = {

  goodPrice: {

    endpoint: "PASTE_GOOD_PRICE_API_URL_HERE",

    serviceKey: "YOUR_GOOD_PRICE_API_KEY",

    pageNo: 1,

    numOfRows: 1000,

    extraParams: {
      type: "json"
    }

  }

};
```

## 수정할 부분

### 1단계

공공데이터포털의 API 상세 페이지에서 **요청주소**를 복사합니다.

예:

```javascript
endpoint: "실제 API 요청주소"
```

### 2단계

발급받은 인증키를 입력합니다.

```javascript
serviceKey: "발급받은 인증키"
```

---

# 8. 식품안심업소 API 설정

식품안심업소는 식품안전나라 OpenAPI를 사용합니다.

`script.js`에서 다음 부분을 찾습니다.

```javascript
safeFood: {

  endpoint: "https://openapi.foodsafetykorea.go.kr/api",

  serviceKey: "YOUR_SAFE_FOOD_API_KEY",

  serviceId: "C004",

  dataType: "json",

  startIndex: 1,

  endIndex: 1000

}
```

다음 부분을 실제 인증키로 변경합니다.

```javascript
serviceKey: "YOUR_SAFE_FOOD_API_KEY"
```

예:

```javascript
serviceKey: "실제발급받은API키"
```



환경에서 테스트하는 것이 안전합니다.

# 21. 현재 위치 기능

현재 위치는 브라우저의 Geolocation API를 사용합니다.

사용자가 위치 권한을 허용하면:

```javascript
navigator.geolocation.getCurrentPosition(...)
```

을 이용해 현재 위도와 경도를 가져옵니다.

위치정보 사용을 거부하는 경우 앱이 중단되지 않고 기본 지역을 사용하도록 구성되어 있습니다.

# 22. 주소 → 좌표 변환

착한가격업소 또는 주차장 데이터에 위도와 경도가 없는 경우 Kakao Maps의 Geocoder 기능을 사용합니다.

HTML에서 다음 라이브러리가 포함되어 있습니다.

```text
libraries=services
```

JavaScript에서는:

```javascript
kakao.maps.services.Geocoder()
```

를 사용합니다.

# 25. 세 공공데이터 연결 방식

서비스의 핵심 구조는 다음과 같습니다.

```text
착한가격업소
      │
      ├── 업소명 / 주소
      │         ↓
      │    식품안심업소 매칭
      │
      └── 위도 / 경도
                ↓
         주변 공영주차장 검색
```

최종적으로 사용자는 하나의 음식점 카드에서 다음을 확인합니다.

```text
음식점
+
메뉴가격
+
식품안심 여부
+
가까운 공영주차장
```

# 26. 음식점과 주차장 거리 계산

음식점과 공영주차장의 위도·경도를 이용하여 거리를 계산합니다.

현재 프로젝트에서는 Haversine 방식의 거리 계산을 사용합니다.

이를 통해:

```text
음식점
↓
300m
↓
500m
↓
1km
```

범위 내 공영주차장을 찾습니다.

# 27. 식품안심업소 매칭

착한가격업소와 식품안심업소는 동일한 데이터셋이 아닙니다.

따라서:

```text
업소명
+
주소
```

를 비교하여 동일 업소일 가능성이 높은 데이터를 연결합니다.

# 49. CORS 문제

일부 공공데이터 API는 브라우저에서 직접 호출할 경우 CORS 정책 때문에 요청이 차단될 수 있습니다.

Console에서 다음과 유사한 오류가 나타날 수 있습니다.

```text
Access to fetch at ...
has been blocked by CORS policy
```

이 경우 JavaScript 문법 오류가 아니라 **API 서버의 브라우저 직접 호출 허용 정책 문제**일 가능성이 있습니다.

상용 프로젝트에서는 Backend Proxy가 필요할 수 있습니다.

# 58. 코드 수정 시 주의

HTML의 주요 `id`와 JavaScript의 DOM 선택자는 연결되어 있습니다.

예:

```html
<div id="searchResultList"></div>
```

JavaScript:

```javascript
document.getElementById(
  "searchResultList"
);
```

HTML의 `id`를 임의로 변경하면 JavaScript가 동작하지 않을 수 있습니다.

CSS 클래스명 역시 같은 이유로 임의 변경에 주의합니다.

# 62. 최종 서비스 정의

**주차한끼는 착한가격업소, 식품안심업소, 전국 공영주차장 공공데이터를 결합하여 가격·식품안심·주차 편의성을 한 번에 비교하고, 자가용으로 방문하기 좋은 음식점을 빠르게 결정할 수 있도록 돕는 모바일 생활정보 앱입니다.**

핵심은 단순히 세 개의 공공데이터를 보여주는 것이 아니라:

```text
음식점 선택
      ↓
가격 확인
      ↓
식품안심 확인
      ↓
가까운 공영주차장 선택
      ↓
방문
```

이라는 하나의 실제 사용자 행동으로 연결하는 것입니다.
