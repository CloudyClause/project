# 할 일 관리 앱 PRD

## 1. 프로젝트 개요

### 프로젝트명

할 일 관리 앱 (가칭: Todo Focus)

### 프로젝트 목적

사용자가 해야 할 일을 빠르게 등록하고, 오늘 해야 할 일을 명확하게 확인하며, 완료 여부를 직관적으로 관리할 수 있는 모바일 중심의 할 일 관리 서비스를 개발한다.

기존 할 일 관리 앱처럼 기능을 과도하게 제공하기보다, 초기 버전에서는 **빠른 입력, 오늘의 할 일 확인, 완료 관리​**에 집중한다.

향후에는 반복 일정, 알림, 집중 모드, 통계 등으로 확장할 수 있도록 구조를 설계한다.

---

## 2. 핵심 목표

본 서비스의 핵심 목표는 다음과 같다.

1. 사용자가 할 일을 3초 이내에 빠르게 등록할 수 있도록 한다.
2. 앱 실행 즉시 오늘 해야 할 일을 확인할 수 있도록 한다.
3. 완료 여부를 체크박스 한 번으로 변경할 수 있도록 한다.
4. 할 일이 많아져도 날짜와 중요도 기준으로 쉽게 관리할 수 있도록 한다.
5. 초기 기능은 단순하게 유지하고, 향후 기능 확장이 가능하도록 설계한다.

---

## 3. 타깃 사용자

### 주요 사용자

- 개인 일정과 업무를 간단하게 관리하고 싶은 사용자
- 복잡한 프로젝트 관리 도구가 부담스러운 사용자
- 오늘 해야 할 업무를 빠르게 정리하고 싶은 직장인
- 공부, 운동, 개인 일정 등을 관리하고 싶은 학생
- 메모 앱보다 조금 더 체계적인 일정 관리가 필요한 사용자

### 사용자의 주요 문제

- 해야 할 일을 여러 곳에 메모해 놓고 잊어버림
- 할 일이 많아지면 무엇부터 해야 할지 판단하기 어려움
- 복잡한 일정 관리 앱은 입력 과정 자체가 번거로움
- 완료한 업무와 남은 업무를 한눈에 파악하기 어려움

---

## 4. 서비스 핵심 가치

### 빠른 입력

복잡한 설정 없이 제목만 입력해도 즉시 할 일을 생성할 수 있어야 한다.

### 오늘 중심

앱 실행 시 가장 먼저 오늘 해야 할 업무를 보여준다.

### 단순한 관리

체크박스, 수정, 삭제 등의 기능을 직관적으로 제공한다.

### 우선순위 명확화

중요한 할 일을 쉽게 구분할 수 있도록 한다.

### 확장 가능성

향후 알림, 반복 일정, 통계, AI 추천 등의 기능을 추가할 수 있도록 설계한다.

### 주요 구성 요소

- 현재 날짜
- 오늘의 완료 현황
- 완료율

- 중요 할 일 표시

오늘 할 일

# 9. 할 일 관리 기능

## 완료

체크박스를 누르면 즉시 완료 처리한다.

완료된 업무는 시각적으로 다음과 같이 표현한다.

- 텍스트 색상 약화
- 취소선 적용
- 체크 표시

완료된 업무는 완료 메뉴에서도 확인할 수 있다.

---

## 수정

사용자가 기존 할 일을 선택하면 수정 화면으로 이동한다.

수정 가능한 항목:

- 제목
- 날짜
- 중요도
- 향후 추가되는 상세 설정

---

## 삭제

사용자가 필요 없는 업무를 삭제할 수 있도록 한다.

삭제 방식은 다음 중 하나를 사용할 수 있다.

- 상세 화면의 삭제 버튼
- 목록 스와이프 삭제
- 더보기 메뉴 → 삭제

삭제 실수를 방지하기 위해 삭제 후 짧은 시간 동안 실행 취소 기능을 제공하는 것도 고려한다.

### 목적

# 25. 비기능 요구사항

### 성능

- 주요 화면은 빠르게 로딩되어야 한다.
- 할 일 추가 및 완료 처리 후 즉각적으로 화면이 반응해야 한다.

### 사용성

- 주요 버튼은 한 손으로 쉽게 누를 수 있어야 한다.
- 모바일 환경에서 작은 버튼 사용을 피한다.

### 안정성

- 데이터 저장 실패 시 사용자에게 오류를 표시한다.
- 중복 클릭으로 같은 할 일이 여러 번 생성되지 않도록 한다.

### 확장성

향후 반복 일정, 알림, AI 기능을 추가할 수 있도록 데이터 구조를 확장 가능하게 설계한다.

# 29. 최종 제품 방향

이 앱의 첫 번째 목표는 복잡한 일정 관리 플랫폼을 만드는 것이 아니다.

사용자가 앱을 열고,

**해야 할 일을 적고 → 오늘 할 일을 확인하고 → 완료하는 흐름을 가장 빠르게 만드는 것**

이 핵심이다.

따라서 Version 1.0은 다음 기능을 중심으로 개발한다.

**오늘 할 일 + 추가 + 수정 + 삭제 + 완료 + 날짜 + 중요도 + 완료 기록**

서비스가 안정화된 이후 반복 일정, 알림, 카테고리, 집중 모드, 통계, AI 기능을 단계적으로 확장한다.
