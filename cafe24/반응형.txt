*** 화면구현 ***
적응형 웹 ->
pc기기에 접속하려면 pc용주소, 스마트폰에 접속하려면 스마트폰용주소 따로 지정
반응형 웹 -> 
pc기기, 태블릿 기기, 스마트폰 등 사이트에 접속하는 기기의 
화면의 크기에 따라서 웹사이트의 레이아웃과 디자인이 
자동으로 유동적으로 조절되는 방식의 웹
pc용 웹주소, 스마트폰용 웹주소가 동일하다

기술적 ->
1. css에서 미디어쿼리를 이용하여 화면의 너비나 해상도를 설정한다

장점 -> 하나의 웹사이트만 관리 하므로 유지보수가 편하다
단점 -> 복잡하고 방대한 데이터를 담아야 하므로 용량크기와
로딩 속도가 느려질수 있다

bootstrap

<반응형 웹 기술>
1. 반응형 웹 구현은 pc기기부터 구현한다
2. 노트북 기기 코딩시 노트북의 해상도를 설정한다 -> 미디어쿼리 설정
@media ( min-width:992px ) and ( max-width:1119px ){
	pc레이아웃을 기준으로
	레이아웃 변경된 요소만 코딩

태블릿
@media ( min-width:768px ) and ( max-width:991px ){
	노트북 레이아웃을 기준으로
	레이아웃 변경된 요소만 코딩

모바일
@media ( min-width:320px ) and ( max-width:767px ){
	태블릿레이아웃을 기준으로
	레이아웃 변경된 요소만 코딩

첨부된 첫번쨰 시안은 pc기기일때이고, 
두번째 시안은 notebook기기 일때,
세번쨰 시안은 tablet기기이며, 
네번째 시안은 모바일 기기일떄 시안이야
위 시안을 바탕으로 미디어쿼리를 사용하여 반응형 웹페이지를 구현해줘

(반응형 브레이크포인트는 320px에서 767px이야)
